# INFOZATECH — Python Development Internship

This repository contains the Python projects completed as part of my **Python Development Internship at InfozaTech**.

The projects focus on building practical Python applications while developing skills in functions, loops, input validation, file handling, data persistence, and basic problem-solving.

## Completed Tasks

### 1. To-Do List App

A command-line task management application that allows users to:

* Add new tasks
* View all tasks
* Mark tasks as completed
* Remove tasks
* Save tasks to a text file
* Load saved tasks when the program starts
* Validate menu choices and task numbers
* Handle empty task lists

**Main concepts:** Functions, lists, loops, file handling, input validation, and data persistence.

---

### 2. BMI Calculator

A command-line BMI calculator that allows users to:

* Calculate BMI using height and weight
* Display the BMI result
* Categorize the BMI result
* Record the date and time of each reading
* View previous BMI readings
* Save readings to a text file
* Load previous readings when the program starts
* Validate user input and prevent invalid values

**Main concepts:** Functions, calculations, conditional statements, exception handling, date/time, and file handling.

---

### 3. Password Generator

A command-line password generator that allows users to:

* Choose the password length
* Require a minimum password length of 8 characters
* Include letters, numbers, and/or symbols
* Validate character-type selections
* Generate random passwords
* Generate multiple passwords in one session
* Display all generated passwords at the end

**Main concepts:** Functions, loops, input validation, the `random` module, the `string` module, and lists.
